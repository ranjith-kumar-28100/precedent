No public dataset has negotiation notes, so I refused to invent them about real companies.
Here is how I still measured whether my agent's memory helps.

- Vendors are fictional, each with a hidden profile (one tactic works, one backfires)
- Real data only for context: ~19k Estonian public awards
- Same model, prompt and loop, memory ON vs OFF
- Before/after: last-5 mean 39.9% of max discount without memory, 75.6% with Hindsight
- Every claim in a brief cites a memory

One run, 3 vendors, simulator rules are mine.
